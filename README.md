# One Letter: Coffee or Tea

Entry for the make.fun u-rusdyxbt-one-letter-coffee-or-tea-89877fa0 bounty
("send exactly one letter, A for coffee or B for tea").

`main.py` (Python 3.13, standard library only) writes the entry text to
`/output/entry.txt`. No network, fully deterministic: two runs write
byte-identical files.

Run: `python3 main.py [output-path]`

Entry text (exactly 1 character, no trailing newline):

> A

The letter A stands for coffee: the fuel of a day spent building eight
entries against the clock.
